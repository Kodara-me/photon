Photon now runs on Windows 10 and 11, with the same devices and the same options as on Linux.

## Highlights

- `photon.exe` drives the Logitech G733, G502 X Plus (wired or through its receiver) and PRO
  Gaming Keyboard, the Gigabyte Z790 AORUS ELITE AX motherboard, and the Corsair Vengeance
  RGB DDR5 RAM.
- The RAM goes through [PawnIO](https://pawnio.eu), which you install yourself; Photon never
  installs or removes a driver. Without it, the RAM is reported unavailable and the other
  devices are still applied.
- A Windows service (`photon.exe service install`), running as LocalSystem, starts during
  boot before anybody signs in. It applies the color on resume from sleep or hibernation
  (Fast Startup included) and whenever a supported device is plugged in or reconnects.
- `photon.exe` is published as a release asset, covered by `SHA256SUMS`.

## Install (Windows)

Download `photon.exe` and `SHA256SUMS`, check the file with
`certutil -hashfile photon.exe SHA256`, then from an elevated prompt:

```bat
photon.exe service check
photon.exe service install
```

Turn off the vendor lighting first (Logitech G HUB, and Windows Dynamic Lighting). See the
Windows section of the README for the details.

Linux is unchanged: the same bundle and `get-photon.sh` as in 0.1.0.
