First public release of Photon, formerly KiraLights.

Photon is a small Linux service that sets one RGB color on supported Logitech, Corsair DDR5
and Gigabyte hardware at boot and after every reconnect.

## Highlights

- Logitech G733, G502 X Plus (USB or Lightspeed receiver) and PRO Gaming Keyboard over HID++.
- Corsair Vengeance RGB DDR5 over SMBus, after verifying each controller's signature.
- Gigabyte Z790 AORUS ELITE AX motherboard and fan lighting through its ITE controller.
- A standalone bundle with `service install` (which also upgrades) and `service uninstall`.
- Read-only probes for every device: `photon probe <device> --json`.

## Upgrading from KiraLights

`sudo ./photon service install` replaces a `kira-lights` installation and keeps its color:
`/etc/kira-lights/config.toml` is copied to `/etc/photon/config.toml`. Remove
`/etc/kira-lights` once Photon runs as expected.

## Install

```sh
curl -LO https://github.com/jstmichel/photon/releases/download/v0.1.0/photon
curl -LO https://github.com/jstmichel/photon/releases/download/v0.1.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
chmod +x photon
sudo ./photon service install
```

The bundle needs Linux with systemd and libudev, x86_64, glibc 2.35 or newer. Stop Solaar
and OpenRGB first.
