Photon now installs on Windows with one command, and can install PawnIO for the RAM.

## Highlights

- `get-photon.ps1`, the Windows one-command installer, is published with each release and
  covered by `SHA256SUMS`. From a standard (not elevated) PowerShell prompt:

  ```powershell
  irm https://github.com/jstmichel/photon/releases/latest/download/get-photon.ps1 | iex
  ```

  It downloads `photon.exe` and checks it against `SHA256SUMS`, runs `service check`, asks
  before installing, and installs the service through its own UAC prompt. It stops early when
  that version is already installed. Options (`-Version`, `-Yes`, `-DryRun`, `-Help`) go
  through the scriptblock form shown in the README.
- When PawnIO is missing, the installer offers to install it, and only does so after an
  explicit yes on the console (never with `-Yes`). It downloads the pinned PawnIO 2.2.0
  installer from its official releases, requires both its pinned SHA-256 and a valid
  Authenticode signature from the pinned signer (subject and thumbprint), and runs it through
  its own UAC prompt. A refusal or a failed install leaves only the RAM disabled.
- `photon.exe service check` and `service install` still never download or install a driver.
  A missing PawnIO now points to `get-photon.ps1` and https://pawnio.eu.

## Install (Windows)

Run the command above from a standard PowerShell prompt. The manual flow (`certutil`,
`service check`, `service install` from an elevated prompt) is still documented under
"By hand" in the README.

Linux is unchanged: the same bundle and `get-photon.sh` as in 0.2.0.

*Français* — Photon s’installe maintenant sous Windows en une commande, avec `get-photon.ps1`,
lancé depuis une invite PowerShell standard. Quand PawnIO manque, l’installeur propose de
l’installer : il ne le fait qu’après un oui explicite, vérifie le SHA-256 et la signature
épinglés de l’installeur officiel de PawnIO 2.2.0, et le lance derrière sa propre invite UAC.
L’installation à la main reste documentée dans le README.
